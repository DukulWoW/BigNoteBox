
# BigNoteBox v1.10.0

## New
- Traditional Chinese (zhTW) clients now get their own font picker, with four fonts from the BigNoteBox Fonts CN pack

## Change
- Buttons throughout BigNoteBox now use Blizzard's current, sharper button style
- WoW Forever: the character sidebar's slot borders now match Forever's own UI art, with a hover highlight on unselected slots
- WoW Forever: windows now use a wood-grain background that matches Forever's own UI

## Fixed
- Note settings: the Use Default and Random icon buttons no longer sit below the window's edge
- WoW Forever: window borders no longer crowd the contents. Every window now has the same spacing around its content as on Retail
