# BigNoteBox v1.10.0

## All versions

### New
- Traditional Chinese (zhTW) clients now get their own font picker, with four fonts from the BigNoteBox Fonts CN pack

### Change
- Buttons throughout BigNoteBox now use Blizzard's current, sharper button style

### Fixed
- Note settings: the Use Default and Random icon buttons no longer sit below the window's edge

## WoW Forever only

### Change
- The character sidebar's slot borders now match Forever's own UI art, with a hover highlight on unselected slots
- Windows now use a wood-grain background that matches Forever's own UI

### Fixed
- Window borders no longer crowd the contents. Every window now has the same spacing around its content as on Retail
