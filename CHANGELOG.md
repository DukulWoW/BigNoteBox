# BigNoteBox v1.29.0

## All versions

### New
- Right-click a link in a note, rich or normal, for a menu: Send to chat, Show and Try on for items; Set waypoint, Show on map, Send to chat and Copy /way for waypoints; Open note and Share to chat for links to other notes; Send to chat and Copy link for web links.
- The right-click menu in the note text now holds the note token groups, the same as the toolbar's token button, in place of the old insert rows; new token {{datetime}} for the date and time together.
- Links to other notes show in that note's title colour, and follow it when it changes.

### Change
- Note tokens in a normal note become their value as you type or pick them (your gold, an item's link, your own tokens); rich notes keep them live and filled each time they are shown. A rich note made normal gets the values of that moment.
- Clicking an item or other game link in a normal note works as in a rich note (the card, Ctrl+click to try it on); Shift+click sends a link to chat in both, opening the chat line if it is closed.
- Send to chat goes straight into BigChatBox's chat line when BigChatBox is on.
- Reference Box right-click menus show the entry's name at the top and an icon on every row.
- The note token lists call their groups Here and now and Character, and their tooltips say how tokens fill in rich and normal notes.
- The note toolbar's overflow menu uses short names (Restore point, History, Alarm, Copy / Move, Share, Show on map); the longer text is in the tooltip.
- Settings > Backup shows the Rescue section only while there are notes to rescue, at the top of the page, so the page no longer needs a scrollbar.
- Simplified Chinese: everything added since the last translation is translated (templates, tags, note tokens, links, Rescue and more).

### Fixed
- Up and Down move through the token list again in notes, Focus mode, sticky editing and the tl;dr boxes.
- Pressing Enter at the bottom of a note scrolls the note along, so the line you are typing stays in view.
- Clicking the note title to rename it frames only the title, not the tl;dr line above it.
