# BigNoteBox v1.25.0

## All versions

### New
- Top bar menu. Pick which icons stay on the top bar and which go into the menu; icons that do not fit a narrow window move into it instead of covering the sort buttons. The sidebar toggle now lives at the bottom of this menu.
- Two new icon categories, Stone tablets and Storage (49 bags).

### Change
- Toast style arrows and button are greyed out while Follow my faction is ticked.

### Fixed
- In a narrow window the Select mode buttons no longer run off the window: the ones that do not fit are in the top bar menu.
- Turning off Sticky Notes no longer leaves an empty gap in the note's action bar.
- The right-click menu in a note now opens anywhere in the writing area, not only over the text.

## Classic only

### New
- Many more note icons: letters, books, race heads, faction tokens and gifts.
