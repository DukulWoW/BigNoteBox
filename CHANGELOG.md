# BigNoteBox v1.23.1

## All versions

### Change
- The bundled fonts now ship with their license files (Assets/Fonts/OFL.txt and OpenDyslexic-LICENSE.txt).
- Simplified Chinese: every string added since v1.21 is translated, and the older strings use the same words throughout (toasts, alarms, Reference Box, Oracle, snooze).

## Classic only

### Change
- The Report a bug button sits beside the main window, with a red glow, as on WoW Forever (it was beside the Settings window).
- The language selector is now on Classic too (Settings > General and the setup wizard).

### Fixed
- Reference Box "Show IDs" adds the ItemID and SpellID lines to tooltips (they were missing).
- TBC Anniversary and MoP: the tl;dr line shows in the game tooltip of a player or NPC with a note.
